Part 00

Orientation — don't skip this

If you've never touched code, read this once. It's the whole vocabulary you need. Ten minutes here saves you an hour of confusion later.

TERMThe words

WordWhat it actually means
PowerShell / TerminalA black text window where you type commands instead of clicking. On Windows it's called PowerShell. This is where most of the magic happens.
CommandA line of text you type (or paste) into PowerShell, then press Enter to run it. Example: node -v
Paste into PowerShellCopy the text, click inside the PowerShell window, then right-click (right-click = paste there). Press Enter.
FileA single document on your computer, like CLAUDE.md. It has a name and an ending (.md, .py, .env).
FolderA container that holds files. We'll make one called Jarvis.
API keyA long secret password that lets your Jarvis use a company's service (like Claude's brain or a voice). Treat every key like a credit card number.
InstallDownload and set up a program so your computer can use it. Usually one command or one installer file.
MCP serverA "plug-in" that gives Jarvis a new ability — reading your vault, driving a browser, etc. You'll add these with a small config file.
SkillA saved instruction pack that makes Jarvis better at one thing (designing UIs, reviewing code). You install these into its "brain."
Claude CodeThe AI coding assistant that will actually build Jarvis for you. You talk to it in plain English and it writes the code.

HOWHow to open PowerShell (you'll do this a lot)

  1. Press the Windows key

    Bottom-left of your keyboard, the little window flag.

  2. Type powershell

    Just start typing the word. "Windows PowerShell" appears at the top.

  3. Click "Run as administrator" the first few times

    Right-click "Windows PowerShell" → Run as administrator → click Yes. This gives it permission to install things. After setup you can open it normally.

The one habit that makes this easy: when this guide shows a command box, copy the whole thing, right-click into PowerShell to paste, press Enter, and wait until the text stops scrolling and you get a fresh line before doing the next one. Never rush two commands together.
Golden safety rules — memorize these: (1) Never paste an API key into a website, chat, or anywhere public. (2) Jarvis will always ask before it sends an email, spends money, or posts anything — never remove that confirmation. (3) If a command errors, don't panic — copy the red text, paste it to Claude Code, and ask "what does this mean and how do I fix it?"
Part 01

Install the foundation software

Eight programs. Install them in this order. After each one there's a verify command — run it, and if it prints a version number, that piece is done.

1 of 8Google Chrome

Jarvis's voice input needs Chrome specifically (not Edge, Safari, or Firefox). Go to google.com/chrome → click Download Chrome → open the downloaded file → follow the installer.

2 of 8Node.js (this gives you npm)

Go to nodejs.org → click the big button that says LTS (Long Term Support) → open the downloaded .msi file → click Next / Next / Install, accept the license, leave every default checked. When it asks about "Tools for Native Modules," you can leave it unchecked.

PowerShell — verify Node installed
node -v
npm -v

If you see two version numbers (like v22.3.0 and 10.8.1), you're good. If it says "not recognized," close PowerShell, open it again, and retry.

3 of 8Python 3.12+

Go to python.org/downloads → click Download Python 3.12 (or newer). CRUCIAL: on the very first installer screen, check the box at the bottom that says "Add python.exe to PATH" before clicking Install. Miss this and nothing works later.

PowerShell — verify Python
python --version
pip --version

4 of 8Git

Git downloads code projects ("repos") from the internet. Go to git-scm.com/download/win → the download starts automatically → open the file → click Next through every screen (all defaults are fine).

PowerShell — verify Git
git --version

5 of 8Visual Studio Code (your editor)

This is where you'll create and view files. Go to code.visualstudio.com → Download for Windows → open the file → accept the agreement → on the "Select Additional Tasks" screen, check "Add to PATH" and both "Open with Code" boxes → Install.

Then open VS Code and install two extensions: click the squares icon on the left (Extensions), search "Python" (by Microsoft) → Install, then search "Claude Code" → Install.

6 of 8Claude Code (the builder)

This is the AI that builds Jarvis. Install it with one command, then sign in.

PowerShell — install Claude Code
npm install -g @anthropic-ai/claude-code
PowerShell — sign in
claude

The first time you run claude, it opens your browser to log in. Sign in with your Anthropic account (make one at claude.ai if you haven't). Once it says you're connected, type /exit and press Enter to close it for now.

If npm install -g gives a permissions error: run this once, then retry the install command above: npm config set prefix "$env:APPDATA\npm"

7 of 8Codex (optional second engine)

Codex is a second AI coding engine Jarvis can route heavy jobs to. It's optional for Stage 1 — you can skip it now and add it later. If you want it, install the Codex CLI per its official docs and sign in the same way. Everything in this guide works with just Claude Code.

8 of 8Obsidian (the memory app)

Go to obsidian.md → Download → open the file → it installs itself. Don't create a vault yet — we do that carefully in Part 3.

✅ Part 1 test: open a fresh PowerShell and run these four — every one should print a version. If so, your foundation is complete.

node -v   python --version   git --version   claude --version
Part 02

Get your API keys

Keys are passwords that let Jarvis use outside services. You need three to start. Two are free. Open a blank note in Notepad and paste each key in as you get it — you'll need them all in Part 5.

Before you begin: a key is like a credit card number. Never put one in a website form, a screenshot, a public GitHub repo, or a chat message. They only ever go in one place: your .env file on your own computer.

KEY 1Anthropic — the brain Required

  1. Go to console.anthropic.com

    Sign in with the same account you use for Claude.

  2. Add credits first

    Click Billing in the left sidebar → Add credits. Put in $20 to start and turn on Auto-reload so Jarvis never dies mid-sentence.

  3. Create the key

    Left sidebar → API Keys → Create Key → name it jarvis → Create.

  4. Copy it immediately

    It starts with sk-ant-. You can only see it once — paste it into your Notepad now. If you lose it, just delete it and make a new one.

Cost reality: expect roughly $5–20/month for normal personal use. Heavy building days cost more. The auto-reload cap is your safety net — set it to something you're comfortable with.

KEY 2Groq — the ears (speech to text) Free

  1. Go to console.groq.com

    Create a free account (Google sign-in is fastest).

  2. Left sidebar → API Keys → Create API Key

    Name it jarvis → Submit.

  3. Copy it

    Starts with gsk_. Paste into Notepad.

Groq runs Whisper (the transcription model) extremely fast and gives you a generous free tier — this is what turns your voice into text for Jarvis.

KEY 3ElevenLabs — the voice Free tier

  1. Go to elevenlabs.io

    Create a free account.

  2. Click your profile icon (bottom-left) → API Keys

    Create a key and copy it into Notepad.

  3. Pick your Jarvis voice

    Go to the Voices library and find a calm British male voice. Click it, then copy its Voice ID (a long string of letters/numbers) into Notepad too — labeled ELEVENLABS_VOICE_ID.

Free tier is ~10,000 characters/month — enough to test properly. If you fall in love with it, the $5/month tier is plenty for daily personal use.

LATERKeys you'll get in Part 7 (skip for now)

  • Telegram Bot Token — free, for texting Jarvis. We create it in Part 7.
  • Twilio SID + Auth Token + phone number — ~$1/month + usage, for calling Jarvis. Part 7.
✅ Part 2 test: your Notepad should now have 4 lines — Anthropic key, Groq key, ElevenLabs key, ElevenLabs voice ID. Save that Notepad file somewhere private on your own machine (not a shared drive).
Part 03

Set up Obsidian — Jarvis's memory

Obsidian is just a folder of plain text files with a nice app on top. That's exactly why it's perfect for memory: Jarvis can read and write it directly, you can read it too, and it's yours forever with no lock-in.

3.1Create the vault

  1. Open Obsidian

    You'll see a welcome screen with a few options.

  2. Click "Create new vault"

    It's the first option under "Vaults."

  3. Name it JarvisVault

    Type exactly that name.

  4. Set the location

    Click Browse and choose C:\Users\DanGi. The final path will be C:\Users\DanGi\JarvisVault. Click Create.

Using a different Windows username? Everywhere this guide says C:\Users\DanGi, swap in your own. To find it, run echo $env:USERPROFILE in PowerShell — whatever it prints is your home folder.

3.2Build the folder structure

This structure is the shape of Jarvis's mind. Rather than clicking 12 times, create it in one command.

PowerShell — create the vault skeleton
cd $env:USERPROFILE\JarvisVault
mkdir Jarvis, Jarvis\memory, Jarvis\knowledge, Jarvis\logs, Summit, Projects, Daily

Part 06 · Stage 2

Give Jarvis hands — the MCP tools

Right now Jarvis can think and talk. MCP servers are plug-ins that let it do things: read your vault properly, control files and the terminal, drive a browser, see your calendar and email, and edit code surgically.

6.1How MCP works in one paragraph

An MCP server is a small program that exposes a set of abilities. You register it once, and from then on Claude Code can call it. Registration is a single command per server. You do not need to understand what's inside them.

6.2Install the core tools

Run these one at a time in PowerShell from your Jarvis folder. Wait for each to finish before the next.

PowerShell — Obsidian vault access
cd $env:USERPROFILE\Jarvis
claude mcp add obsidian -- npx -y obsidian-mcp "C:\Users\DanGi\JarvisVault"

Now Jarvis can list, read, search, create and edit notes in your vault as structured operations instead of raw file pokes.

PowerShell — files + terminal control
claude mcp add desktop-commander -- npx -y @wonderwhy-er/desktop-commander

10.4Security checklist — review this monthly

  • Is .env in .gitignore? Run git status in the Jarvis folder. If .env appears in the list, stop and fix it immediately.
