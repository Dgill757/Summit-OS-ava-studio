Fix Your Credit Problem First (Read This)

You said you're burning all your credits and tokens. This is the single most important section. Here's the exact strategy to cut your spend by 60–90% while keeping quality.

⚠️
The mistake: Running Opus (or a top-tier model) for the entire build — including boilerplate, file scaffolding, and simple sections. That's like paying a $500/hr architect to hammer nails. The fix is a manager/worker split plus token-saving memory tools.
✅ The Cheap Setup (do this)
• Sonnet 4.6 as your daily driver — 90% of the build. $3/1M input.
• Opus 4.8 only for: the 3D/animation foundation, complex architecture, and when Sonnet breaks 2+ times.
• Gemini 2.5 Pro (free) for scaffolding — full site skeleton at zero cost, then polish in Claude Code.
• Caveman + memory tools to cut token use 65%+.
• gitingest / crawl4ai to feed Claude clean context instead of raw HTML.
❌ What's Draining You
• Running Opus for the whole session
• Re-pasting the same context every message (no memory)
• Feeding raw scraped HTML (huge token bloat)
• Letting Claude re-read the entire codebase each turn
• Not using free Gemini for the boring scaffold
• Building from scratch when Firecrawl + clone is 5x faster
🧠
On your "Fable 5 as manager, Opus as worker" idea: This is a real, smart pattern (see the Orchestration section). Since Fable 5 routes some queries to Opus 4.8 via safeguards anyway, the cleaner version in practice is: use one strong model as the planner/reviewer, and cheaper Sonnet agents as the workers. The planner writes the spec + reviews; the workers execute. You'll see the full setup below with the actual repos that make it work (ECC, get-shit-done, 12-factor-agents).

01 — Cursor Effects

A custom cursor is the first thing visitors notice — it signals craft. Four types: magnetic (snaps toward buttons), trail/blob (glowing shape follows with lag), spotlight (circle of light on dark bg), custom SVG (branded icon replaces arrow).

globals.css — spotlight cursor
body { cursor: none; } .cursor { position: fixed; pointer-events: none; z-index: 9999; width: 24px; height: 24px; border-radius: 50%; background: rgba(249,115,22,0.6); /* your brand accent */ transform: translate(-50%, -50%); transition: transform 0.1s ease, width 0.2s, height 0.2s; }
JS — attach cursor movement + hover scale
const cursor = document.querySelector('.cursor'); document.addEventListener('mousemove', e => { cursor.style.left = e.clientX + 'px'; cursor.style.top = e.clientY + 'px'; }); document.querySelectorAll('a,button').forEach(el => { el.addEventListener('mouseenter', () => cursor.style.transform = 'translate(-50%,-50%) scale(2)'); el.addEventListener('mouseleave', () => cursor.style.transform = 'translate(-50%,-50%) scale(1)'); });
💬
Prompt: "Add a magnetic cursor effect to all .btn elements using GSAP" — or — "Add a spotlight cursor: dark overlay with a circle of light following the pointer, disabled on mobile."

04 — Micro-interactions

Tiny animations that make the interface feel alive. Clients can never name them, but always notice. Button hover (scale + shadow + color shift), form focus ring, loading skeleton, scroll-triggered reveal, toggle spring, toast notifications.

Scroll-triggered reveal — CSS
.reveal { opacity: 0; transform: translateY(28px); transition: opacity 0.6s ease, transform 0.6s ease; } .reveal.visible { opacity: 1; transform: translateY(0); }
IntersectionObserver — fires reveal once
const observer = new IntersectionObserver(entries => { entries.forEach(e => { if (e.isIntersecting) { e.target.classList.add('visible'); observer.unobserve(e.target); // fire once } }); }, { threshold: 0.15 }); document.querySelectorAll('.reveal').forEach(el => observer.observe(el));
⏱️
Keep toggle/spring animations under 300ms. Every premium site uses scroll-triggered reveals — it's the baseline, not a bonus. In React, use Framer Motion's whileInView instead of the observer.

★ Bonus — Shape Blur Effect (Cursor-Reactive Glow)

A soft glowing blurred shape that follows the cursor or sits behind content. On every AI/SaaS landing page right now — adds depth with zero imagery. Two modes: static ambient glow behind hero text, or cursor-reactive with lag.

CSS — the blob (static glow)
.blur-shape { position: absolute; width: 420px; height: 420px; background: radial-gradient(circle, rgba(249,115,22,0.55), transparent 70%); /* brand accent */ filter: blur(60px); border-radius: 50%; pointer-events: none; z-index: 0; } .blur-shape.follow { position: fixed; top: 0; left: 0; transition: transform 0.3s ease-out; }
JS — make it follow the cursor with a lag
const blob = document.querySelector('.blur-shape'); let mouseX = 0, mouseY = 0, x = 0, y = 0; document.addEventListener('mousemove', e => { mouseX = e.clientX; mouseY = e.clientY; }); function animate() { x += (mouseX - x) * 0.08; // lag factor — lower = dreamier trail y += (mouseY - y) * 0.08; blob.style.transform = `translate(${x - 210}px, ${y - 210}px)`; requestAnimationFrame(animate); } animate();
💡
Lower the lag factor (0.08 → 0.04) for a slower trail · use 2–3 overlapping blobs in different colors for richness · keep z-index below text · disable cursor-follow on mobile (no mouse), keep static. Prompt: "Add a blurred radial gradient shape that follows the cursor with a smooth lag, behind the hero content."
